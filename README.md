# The Sundered

A Riftborn progression RPG set in a world fractured by rifts. Build a character, explore locations, collect gear, evolve a class, meet companions, and survive combat in a persistent browser save.

## Run locally

```bash
npm ci
npm run dev
```

Create a production bundle with `npm run build`.

## Built with

React, TypeScript, Vite, Zustand, and Framer Motion. Saves are stored in the browser's local storage.
